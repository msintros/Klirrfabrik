# Klirrfabrik
Multi-band distortion loosely inspired by Quadrafuzz.  

* 18 different distortion algorithms.  

* Up to 8x oversampling.

* Optional Noise Gate and Filter.

* Individual drive, level, and mix controls for each band.

* User-selectable color for spectrum visualizer.

Actual code is 100% Claude.  No Steinberg property was used here, and none of my prompts to Claude even made mention of Quadrafuzz.
